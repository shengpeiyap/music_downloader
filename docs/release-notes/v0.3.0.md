# MusicDesk v0.3.0

v0.3.0 是一次界面与功能的大更新：全新的导航与布局、均衡器、双语歌词、歌单批量下载、更聪明的歌词匹配，以及大量手机端的修复。

v0.3.0 is a major UI and feature update: a redesigned layout, an equalizer, bilingual lyrics, playlist batch download, smarter lyric matching, and many Android fixes.

## 界面 / Interface

- **全新导航**：下载、编辑、播放、设置四个页面，手机上使用底部导航栏。网页版和手机版共用同一份页面。
- **迷你播放器常驻**：在下载、编辑、设置页也能看到当前歌曲，点一下进入正在播放。
- **下载设置**改为选项卡片：手机上是底部弹出面板（可下滑关闭），电脑上是侧边面板。
- **编辑页**：常用字段在前，歌词、裁剪和更多信息折叠成行，按需展开。
- **播放器**：曲目操作收进 “⋯” 菜单，控制按钮位置固定。
- **首次使用引导**：三步介绍，可跳过，只显示一次。
- **英文界面**：补齐运行时提示和动态文字的翻译，长英文按钮不再撑宽页面。

## 新功能 / New features

- **均衡器**（设置 → 音效）：5 个频段和多个预设，设置会保存。电脑和手机都可以用。
- **双语歌词**：同一时间戳的两行显示为“原文 + 小字译文”，可在设置里关闭；编辑页可以把整段译文按行合并进带时间戳的歌词。
- **歌单批量下载（电脑）**：粘贴 YouTube / YouTube Music 歌单链接，勾选曲目后逐首下载并打包成一个 ZIP；失败的曲目会跳过并列出，可以随时取消。
- **其他匹配结果**：关键词搜索后可以展开 MusicBrainz 的其他候选，选一个重新套用专辑和年份。
- **编辑页读取更多标签**：音轨号、碟号、流派、作曲。
- **编辑页显示歌词格式**：选择音频后会显示歌词存放在哪些标签字段（如 `ID3 USLT + ID3 SYLT`），以及是否带时间戳；修改歌词后会提示“保存后写入”。
- **手机连接电脑**：分步骤说明、状态标记，并列出连接后可以解锁的功能。

## 改进与修复 / Improvements and fixes

- **歌词匹配按实际下载的音频**：手机下载完成后，会用视频原标题（例如「アイドル」）和音频时长去查歌词，不会再因为英文译名配到英文版歌词。
- **手机播放器显示内嵌歌词**：支持 MP3（USLT / SYLT / TXXX）、M4A、FLAC、OGG / Opus。
- **播放列表封面**：手机播放列表面板会正常加载每首歌的封面；曲库封面改为按需加载并缓存。
- **YouTube 身份验证**：遇到“确认不是机器人”时自动换用其他播放客户端重试，失败时给出可读的提示。
- **电脑便携版曲库**：修复便携版缺少 `library_sort.js` 导致曲库列表无法显示的问题（v0.2.0 便携版受影响）。
- 写入 MP3/M4A/FLAC/OGG 的歌词现在都能读回；修复部分 M4A、FLAC、OGG 文件读取标签时出错。
- 手机未连接电脑时，独立 `.lrc` 选项会锁定并保留你的选择，不再阻止普通 MP3 下载。

## 注意 / Notes

- 手机上的均衡器通过网页音频处理实现；息屏后台播放已在真机上验证。较强的低音预设在响亮的歌曲上可能出现削波。
