# Support

- **Bug reports:** open a GitHub issue using the bug report form and include reproduction steps, platform, app version, and relevant logs with secrets removed.
- **Feature requests:** open an issue using the feature request form. Explain the use case and affected platform.
- **Security concerns:** follow [SECURITY.md](SECURITY.md); do not post vulnerabilities publicly.
- **Usage questions:** start a GitHub Discussion if available, or use a relevant existing issue.

MusicDesk is maintained as a community project. Support is best-effort; no response time or compatibility guarantee is promised.
