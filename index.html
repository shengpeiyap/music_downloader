MusicDesk 使用帮助

在线解析与下载

粘贴 Spotify、YouTube 分享链接或输入歌曲关键词，读取公开曲目信息、查看歌词、下载音频；也可将本地音频转换为其他格式。

自定义封装

选择本地音频后可试听、裁剪头尾、修改曲目信息和封面；同步歌词可逐句校时，纯文本歌词可制作时间戳并生成 LRC。

本地离线播放器

选择歌曲或文件夹建立曲库，浏览标签、专辑封面和歌词；支持队列、收藏、播放模式与上次播放状态恢复。

键盘快捷键

  • Space 或 K：播放 / 暂停当前页面的音频。
  • ← / →：后退 / 前进 5 秒。
  • M：纯文本逐句打点模式下，标记当前句并前进。
  • T：将选中的 LRC 歌词时间设为当前播放位置。

输入框、歌词文本框和进度滑杆获得焦点时，快捷键不会拦截输入或滑杆操作。打点使用 M，播放暂停使用 Space / K，二者互不冲突。

下载

MusicBrainz 曲目信息、LRCLIB 歌词和 yt-dlp 下载可由手机联网使用。

曲目信息搜索

粘贴 Spotify / YouTube 分享链接，或搜索“作者 - 标题”及单独标题

    音效

    只对“音乐”页的播放器生效；调节后立即听到效果。

    电脑连接

    未连接

    连接后，下载、转换和歌词等任务交给电脑处理，结果传回手机；不连接也能用手机本机功能。

    1. 在电脑上双击 start_lan.bat 启动。
    2. 窗口里会显示“Phone server address”和“One-run pairing token”。
    3. 手机和电脑连同一个 Wi‑Fi，把它们填在下面。

    尚未连接

    连接电脑后可用
    • WAV、FLAC、AAC 等所有格式和比特率
    • SpotDL 来源与在线标签搜索
    • 歌词下载与格式转换

    手机配对

    想让手机用这台电脑处理下载和转换：

    1. 关闭当前窗口，改用 start_lan.bat 启动。
    2. 窗口会显示“Phone server address”和“One-run pairing token”。
    3. 在手机 MusicDesk 的“设置 → 电脑连接”里填入。

    密钥每次启动都会变化，只在你信任的家庭或办公 Wi‑Fi 中使用。

    曲库与权限

    MusicDesk 仅访问你选择的文件夹。撤销授权后，下次启动将不再自动载入该文件夹；当前已载入的曲目会保留到本次使用结束。
